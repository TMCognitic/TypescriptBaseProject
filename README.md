# TypescriptBaseProject

## Mise en place

1. Installer nodejs [https://nodejs.org/fr/download](NodeJs)
2. Se placer dans le répertoire de vos projets (ce répertoire doit exister au préalable) et faire le git clone

``` bash
cd /source
git clone https://github.com/TMCognitic/TypescriptBaseProject.git
```

3. Se placer dans le répertoire créé

``` bash
cd TypescriptBaseProject
```

4. installer les modules

``` bash
npm install
```

5. Lancer les commandes pour démarrer vos projets

``` bash
# npm run watch (recompile à chaque sauvegarde)
npm run watch
# npm run serve (fourni la page avec un rechargement automatique)
npm run serve
```
